# D&D Homebrew — El Códice de Clases

Colección de 43 clases homebrew de D&D 5e, en español. Cada clase es un HTML autónomo con su propia ficha y rastreador de recursos.

- `index.html` — El Códice: índice con buscador, filtro por rol y vista de mapa. Abre las clases en un atril lateral.
- `clases/` — un HTML por clase.
- `contexto/` — documentos de contexto (decisiones de diseño, fusiones, bajas y novedades) para retomar el trabajo.
- `compendio/` — compendio de las 43 clases con su índice (`index.html`), datos (`datos.js`) y lector (`lector.js`).

Los HTML se abren directamente en el navegador; con GitHub Pages el Códice funciona como sitio web.
